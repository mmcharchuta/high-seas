# Contributing to High Seas

Thanks for your interest in contributing! We welcome improvements, bug fixes, documentation updates, and new features.

- Report bugs or request features by opening an issue.
- For code changes, open a pull request (PR) against main.
- Include a clear description of the change and why it is needed.
- If the change includes code, add or update tests where applicable.
- Keep commits focused and with clear messages.

Suggested commit message style:
- Use present tense, short summary in the first line.
- Optionally add a longer description below.

Example:
```
Add phage-detection module

Adds a first-pass implementation of phage interaction detection using
k-mer overlap. Includes unit tests and sample data.
```

Coding style:
- Prefer readable, documented code.
- Document functions and modules with brief docstrings/comments.
- Add tests for non-trivial logic.

License and CLA:
By contributing, you confirm your contribution can be licensed under the project MIT License.

Code of Conduct:
Be respectful and professional. If you want, we can include a separate CODE_OF_CONDUCT.md later.

Thank you for contributing!
